### Applied AI — What I Am Building Now

- **Cortex CLI** — A coding agent harness on Pi that brings agent memory into the agent loop.  
  - Repo memory is stored with its source files and commit, and is checked against current code before reuse.  
  - User corrections become rules with checks on tool-call, file-write, and stop hooks.  
  - A per-turn router selects compression layers and model tier, to cut tokens without loss of quality.  
- **AgentGarage** — Agent systems on **AWS** services, with a focus on **world models**.  
- **On-device agent (in progress)** — A fully offline, self-improving phone agent that selects its own training data and trains itself at night. Focus: edge inference, RL, and model training.
